# Resolution Desk MCP smoke fixture

This task is a deterministic, no-network, no-model, no-spend fixture for the
Agoragentic Cohort Assurance contracts. The four records are synthetic test
controls, not people or representations of people. The task may support only
system-behavior observations.

`target_config.example.json` documents the future target contract. The current
alpha has no external runner and cannot call that target.
