# Presenter guide

The canonical illustrated, browser-readable guide is [public/presenter.html](../public/presenter.html). Open it locally or through the loopback demo server. It includes a plain-language introduction, a three-minute click sequence, actual Node test commands, expected outputs, audience FAQ, and the differences between browser rehearsal, reference execution and the unqualified Dynamic runner.

## The sentence to start with

“This is Agoragentic Risk Fork. The agent chooses the cheapest information source that meets your task, checks untrusted work separately, and keeps wallet authority on the trusted side. This demonstration uses fictional data; its wallet step is not live yet.”

## Recommended live screen-share

Use Node reference mode, not a browser-only animation, when demonstrating the actual protocol. Run the free answer, useful purchase, malicious bargain and revoked-permission presets, in that order. Show exported evidence once. Do not display private credentials, usable signatures or operator files.

A static deployed site is useful for audience exploration, but does not run the Risk Fork backend. Do not call that a live protected wallet. A real Dynamic action remains a separate qualification and rehearsal, required before claiming the sponsor’s working-action requirement is complete.
