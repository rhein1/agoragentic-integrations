03 / RISK FORK

Clone state.
Never authority.

Inspect the untrusted work in a disposable child. Import only an accepted typed artifact after cleanup checks.

Savepoint→Child→Artifact check→Destroy + verify

No wallet credentials, reusable approvals, or trusted memory updates in the child.

The Node example executes the local-reference protocol. That is not production operating-system isolation.
