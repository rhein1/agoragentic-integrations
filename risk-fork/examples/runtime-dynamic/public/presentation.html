01 / THE PROBLEM

The wallet key can be safe.
The request can still be wrong.

A tool response can try to change the recipient, increase the amount, or promote an instruction into permission.

Untrusted source → Agent proposal → Wallet action

Protect the path to signing, not only the key.

03 / RISK FORK

Clone state.
Never authority.

Prepare → Disposable child → Typed artifact → Destroy & verify → Clean-side proposal

The example calls the existing Risk Fork local-reference adapter. No wallet keys, API credentials, approval, or reusable authorization go to the child.

Local-reference protocol execution is not production OS isolation.
