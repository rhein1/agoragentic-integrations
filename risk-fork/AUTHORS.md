# Authors and origin

Agoragentic Risk Fork was created by Jeremy Borden / Agoragentic. The canonical
source is currently the `risk-fork/` directory in
[agoragentic-integrations](https://github.com/rhein1/agoragentic-integrations/tree/main/risk-fork).
Git history records individual contributions; use an exact commit or signed
release when citing an implementation. [CITATION.cff](./CITATION.cff) contains
machine-readable software attribution.

bounded authority-free state, typed taint imports, cleanup evidence, and clean
commit contracts. This is a statement of authorship of Agoragentic Risk Fork,
