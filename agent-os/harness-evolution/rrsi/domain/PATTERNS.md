# Proposal patterns

Prefer a single falsifiable, general mechanism: evidence selection, explicit uncertainty, or bounded context ordering. Reuse the incumbent's demonstrated strengths and review rejected hypotheses before retrying them. Hypothesis evidence must remain scoped to the relevant model, evaluator, dataset and baseline versions.

Initial edit tags are `prompt` for strategy.md and `context_mgmt` for context.md. Structural tool/memory/subagent edits, novelty rewards for those edits and self-expanding authority are excluded from this first tranche. This is a deliberate domain restriction, not the full upstream open edit space.

Pruning requires measured evidence and may remove only candidate-owned optional prompt machinery. It cannot remove base Fable contracts, graders, guards, policy or trial evidence. Critic clearance and a Git diff are not runtime safety proofs.
